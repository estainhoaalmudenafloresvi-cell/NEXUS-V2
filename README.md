# NEXUS — Cadete Explorer

## 1. Nombre del proyecto

**NEXUS v1.0 — Cadete Explorer**

Videojuego de exploración, supervivencia y combate desarrollado en C#.

## 2. Problema

La versión inicial de NEXUS funciona mediante una interfaz de consola. El desafío del proyecto es evolucionar esta versión hacia una aplicación de escritorio con una interfaz gráfica, conservando las mecánicas y la lógica del videojuego existente y preparando una estructura que permita gestionar las partidas mediante una base de datos.

## 3. Propósito

El propósito de NEXUS es ofrecer una experiencia de exploración en la que el jugador asume el papel de un cadete que debe recorrer una realidad desconocida, encontrar un núcleo energético, enfrentarse a entidades hostiles y regresar al punto de extracción.

El proyecto también busca servir como base para aplicar y ampliar los conocimientos de programación orientada a objetos, gestión de estados, interacción con el usuario y persistencia de datos.

## 4. Usuarios

El videojuego está dirigido a personas interesadas en la exploración, la ciencia ficción, la supervivencia y los videojuegos con misiones. También constituye un proyecto académico para aplicar conocimientos de desarrollo de software mediante C#.

## 5. Objetivo

Mantener y mejorar el videojuego desarrollado inicialmente en H3, documentando sus funcionalidades actuales y definiendo una evolución hacia una aplicación de escritorio en C# con Windows Forms y SQL Server.

## 6. Descripción general

NEXUS es un videojuego de exploración ambientado en una realidad desconocida. El jugador controla a un Cadete Explorer y debe administrar su salud, energía, inventario y nivel de radiación mientras recorre el mapa.

La versión actual incluye la misión **«La anomalía perdida»**, cuyo objetivo es recuperar un núcleo energético y regresar al punto de extracción. Durante la exploración, el jugador puede encontrar objetos y enfrentarse a robots o entidades anómalas.

El sistema está organizado mediante clases como `Personaje`, `Cadete`, `Robot`, `Enemigo`, `Mapa` y `SistemaNexus`. La clase `Program` inicia la ejecución del juego.
