# Acciones comprometidas para NEXUS

Este documento recoge solamente los compromisos de la reunión que corresponden a NEXUS.

## Compromisos identificados
1. Corregir GitHub para que muestre las actualizaciones y avances realizados en NEXUS.
2. Mostrar las acciones y cambios efectuados en NEXUS como respaldo del trabajo.
3. Utilizar el historial como guía de estudio para preparar la evaluación y comprender POO.
4. Completar las correcciones observadas antes de la siguiente clase, según el plazo indicado.
5. Aprender a utilizar mejor GitHub para registrar y presentar los cambios del proyecto.

## Acciones concretas
| Compromiso | Acción verificable |
|---|---|
| Actualizar GitHub | Mantener la rama principal sincronizada con el código vigente de Expedición Eos |
| Mostrar cambios | Registrar modificaciones con commits descriptivos |
| Respaldar el trabajo | Versionar código, recursos y documentación |
| Verificar avances | Ejecutar Actions para restaurar y compilar la solución |
| Preparar POO | Estudiar las clases reales con `guia-estudio-poo-nexus.md` |

## Qué hace Actions
El workflow automatiza la restauración de dependencias y compilación en Windows con .NET 8. Los resultados aparecen en la pestaña **Actions**. Una compilación correcta no sustituye pruebas manuales ni verifica una conexión real a SQL Server.

## Registro futuro
Cada avance debe registrar cambio realizado, archivos afectados, motivo, verificación y commit correspondiente. No se deben agregar fechas ni resultados de pruebas que no se hayan realizado.
